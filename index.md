# India data and business resources

Open guides, MCP servers and API notes for a family of India-focused data sites, maintained by Sunny Mittal (marketing lead).

- **[Data Galactica](https://datagalactica.com/)**: A permanent ID for every person and company. [Guide](https://rchtjn2-gif.github.io/datagalactica-guide/)
- **[eCourtsIndia](https://ecourtsindia.com/)**: Search any case in any Indian court, free. [Guide](https://rchtjn2-gif.github.io/ecourtsindia-guide/)
- **[IndiaCos](https://indiacos.com/)**: Know any Indian business before you deal with it. [Guide](https://rchtjn2-gif.github.io/indiacos-guide/)
- **[IndiaInsurances](https://indiainsurances.com/)**: Every Indian insurance policy, read clause by clause. [Guide](https://rchtjn2-gif.github.io/indiainsurances-guide/)
- **[India Property Register](https://indiapropertyregister.com/)**: Every village, plot and property in India. [Guide](https://rchtjn2-gif.github.io/indiapropertyregister-guide/)
- **[IndiaRestros](https://indiarestros.com/)**: Every restaurant, cafe and dhaba in India. [Guide](https://rchtjn2-gif.github.io/indiarestros-guide/)
- **[JurisGrid](https://jurisgrid.com/)**: Every legal tech startup in India, on one grid. [Guide](https://rchtjn2-gif.github.io/jurisgrid-guide/)
- **[RestroCart](https://restrocart.com/)**: Custom uniforms & supplies for Indian F&B brands. [Guide](https://rchtjn2-gif.github.io/restrocart-guide/)
- **[Youth4work](https://youth4work.com/)**: Identify, improve and showcase your talents. [Guide](https://rchtjn2-gif.github.io/youth4work-guide/)

MCP servers and API examples live in the [repositories on this account](https://github.com/rchtjn2-gif?tab=repositories).
